# Native Qt theme geometry

`KvFlat.svg` and `KvFlat.kvconfig` are the KvFlat theme by Tsu Jan from
[Kvantum](https://github.com/tsujan/Kvantum/tree/master/Kvantum/themes/kvthemes/KvFlat),
version 1.1.8 (Arch package). They are redistributed under GPL-3.0-or-later;
see LICENSE. Zephyrus generates a recolored native Kvantum theme from this geometry.
Menus use the surface token; windows, Dolphin's Places panel and file views share
the background token. Text, focus, selection and tabs follow the active palette.
No application code or per-application stylesheet is injected.

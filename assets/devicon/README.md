# Devicon badges

These SVGs are vendored from [Devicon v2.17.0](https://github.com/devicons/devicon/releases/tag/v2.17.0).
The source files are in `icons/<name>/<name>-original.svg`, except `django.svg`,
which uses `django-plain.svg`. The included `LICENSE` applies to the icon set;
product marks remain owned by their respective brands.

Keeping this small, pinned subset in the shell makes project badges work without
a network connection or a CDN dependency. Interface controls continue to use
the shell's bundled Lucide icons.
